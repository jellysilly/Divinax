# ✦ Divinax

Фронтенд для ролевых игр с ИИ в духе SillyTavern: тёмная готическая тема, карточки персонажей, лорбуки, групповые чаты, менеджер промптов и мобильная вёрстка.

Работает целиком в браузере: сервер не нужен, данные хранятся в IndexedDB на вашем устройстве.

## Запуск

```bash
./start.sh         # поставит зависимости, соберёт и запустит на http://127.0.0.1:8000
```

Или вручную:

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build:web  # сборка в dist/
npm start          # сервер для dist/ (без зависимостей): http://127.0.0.1:8000
```

Параметры сервера: `--port 8001` — другой порт, `--listen` — открыть доступ с других устройств в локальной сети, `--no-open` — не открывать браузер.

### Termux (Android)

```bash
pkg update && pkg install nodejs-lts git
git clone https://github.com/jellysilly/Divinax
cd Divinax
./start.sh
```

Браузер откроется сам; если нет — зайдите на http://127.0.0.1:8000. Чтобы Android не усыплял Termux в фоне, выполните `termux-wake-lock`. Для обновления: `./update.sh` — скачает свежую версию из ветки `main` (даже если у вас открыта старая ветка), пересоберёт и запустит. Перед этим остановите запущенный сервер (Ctrl+C). Текущая версия видна во вкладке «Интерфейс» внизу панели «Чат».

Данные хранятся в браузере и привязаны к адресу: запускайте на одном и том же порту, иначе персонажи и чаты «пропадут» (они останутся на старом адресе). Перед сменой устройства сделайте резервную копию во вкладке «Интерфейс».

### Лаунчер для Android

Приложение-лаунчер (папка `android/`) запускает фронт без Termux: сервер встроен в APK, фронт открывается во встроенном окне или в браузере.

- **Запуск:** старт, остановка и перезапуск сервера на `http://127.0.0.1:8000`, автозапуск при открытии лаунчера и вместе с системой. Сервер работает в фоне с уведомлением.
- **Обновления:** берутся из релизов `web-<ветка>`, которые собирает workflow `Web build` при каждом пуше в `main`. Перед обновлением лаунчер сохраняет автобэкап, при ошибке остаётся прежняя версия.
- **Обслуживание:** экспорт и загрузка бэкапа (`.zip`, принимается и `.json` из вкладки «Интерфейс»), переустановка файлов фронта, перезапуск с нуля. Бэкапы сохраняются в `Download/Divinax`.
- **Журнал** всех действий.

Установить: скачайте `DivinaxLauncher.apk` из релиза [launcher](https://github.com/jellysilly/Divinax/releases/tag/launcher) (его собирает workflow `Android launcher`).

Собрать самому (нужны Android SDK и JDK 17+):

```bash
npm ci && npm run build:web   # фронт вшивается в APK
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

Бэкапы и сброс работают с данными встроенного окна. У внешнего браузера своё хранилище, для него пользуйтесь резервной копией внутри фронта. APK подписан общим ключом `android/app/launcher.keystore`, поэтому новые сборки ставятся поверх старых. Чтобы подписать своим ключом, задайте переменные `DX_KEYSTORE`, `DX_KEYSTORE_PASSWORD`, `DX_KEY_ALIAS` и `DX_KEY_PASSWORD`.

## Что уже есть

**Чат**
- стриминг ответов, остановка (Esc), свайпы (← →, новый вариант на последнем), регенерация, продолжение, «ответить за меня»
- редактирование, копирование, удаление, скрытие от ИИ, ветки и контрольные точки
- рассуждения модели (`<think>` и reasoning API) в сворачиваемом блоке
- заметка автора (глубина, роль, частота), быстрые ответы, прикрепление картинок
- slash-команды: `/sys`, `/continue`, `/regen`, `/sum`, `/roll`, `/bg`, `/persona`, `/hide`, `/setvar`… (`/help` — полный список)
- файлы чатов: список, поиск, переименование, импорт/экспорт JSONL (формат SillyTavern) и TXT

**Персонажи и группы**
- импорт PNG/JSON-карточек (spec v1/v2/v3, перетаскиванием в окно или по ссылке chub.ai), экспорт PNG со встроенным лорбуком
- все поля карточки: альтернативные приветствия, примеры диалогов, системный промпт, инструкции после истории, заметка на глубине
- свои аватарки и обложки с обрезкой прямо в браузере: перетаскивание, масштаб (щипок, колёсико), поворот, пропорции 1:1 / 2:3 для аватара и 9:5 / 16:9 / 3:1 для обложки
- теги, избранное, сортировка, галерея
- групповые чаты: естественная очередь (упоминания и разговорчивость), по списку, по одному, вручную

**API**
- Chat Completion: OpenRouter, OpenAI, Claude, Gemini, DeepSeek, Mistral, Groq, xAI, любой OpenAI-совместимый; обратный прокси
- Text Completion: KoboldCpp, llama.cpp, ooba, TabbyAPI, vLLM, Ollama
- KoboldAI, AI Horde, NovelAI
- профили подключений

**Генерация и формат**
- пресеты сэмплеров (импорт пресетов SillyTavern), менеджер промптов с перетаскиванием и инъекциями на глубину
- шаблон контекста (`{{#if}}…{{/if}}`), Instruct-шаблоны (ChatML, Llama 3, Mistral, Gemma, Alpaca, Metharme, Vicuna), системные промпты
- макросы: `{{char}}`, `{{user}}`, `{{random::…}}`, `{{roll:2d6}}`, `{{getvar}}`/`{{setvar}}`, `{{time}}`, `{{idle_duration}}`…
- просмотр промпта: что именно и сколько токенов уходит модели

**Лорбук (World Info)**
- ключи и /регулярки/, вторичные ключи с логикой И/НЕ, постоянные записи
- 7 позиций вставки, глубина, порядок, вероятность, группы включения
- рекурсия, липкость, перезарядка, задержка, бюджет контекста
- сколько угодно лорбуков одновременно: во всех чатах, в конкретном чате, у персонажа (основной + дополнительные) и у персоны; импорт/экспорт формата SillyTavern
- меню «Активные лорбуки» (кнопка «Лорбук» над чатом со счётчиком, меню чата): что включено, откуда и переключатели «Везде / Этот чат / Персонаж»

**HTML, CSS и JavaScript в сообщениях** (как в SillyTavern + Tavern Helper)
- HTML и CSS из ответов модели и регексов рендерятся как есть: плашки, статус-панели, HUD, таблицы, `<details>`; макросы `{{char}}`, `{{user}}`, `{{random}}` подставляются при показе
- `<style>` сообщения действует только внутри него (Shadow DOM) и не ломает интерфейс; опасные атрибуты вроде `onerror` вырезаются (DOMPurify)
- регексы бывают глобальные, привязанные к пресету (меняются вместе с пресетом, импортируются из пресетов SillyTavern `extensions.regex_scripts`) и из карточки
- регексы: «Только показ» для плашек, `$1`, `$<имя>`, `{{match}}`; регексы из карточек (`extensions.regex_scripts`) применяются автоматически
- блоки ```` ```html ```` с разметкой показываются как HTML, а не как код
- `<script>` и блоки ```` ```html ```` с документом выполняются в iframe-песочнице: без доступа к ключам API и данным Divinax, высота подстраивается сама
- из скрипта доступно: `Divinax.triggerSlash('/cmd')`, `Divinax.sendMessage(text)`, `Divinax.fillInput(text)`, `Divinax.getVar(k)` / `setVar(k, v)`, `Divinax.getContext()` (все возвращают Promise); алиасы `triggerSlash`, `getChatVar`, `setChatVar`
- выключается во вкладке «Интерфейс» → «HTML и CSS в сообщениях» / «JavaScript в сообщениях»

**Персоны** — несколько персон с аватарами, размещение описания, привязка к чату и персонажу.

**Интерфейс** — английский (по умолчанию) и русский язык, 5 тем + свои, цвета, шрифт, орнаменты, стиль сообщений (плоский/пузыри/документ), положение аватара (сверху/сбоку/без аватара), фоны — прозрачный, белый, чёрный или своя картинка (свой для каждого чата), резервная копия всех данных.

**Расширения** — суммаризация, регулярные выражения, быстрые ответы, озвучка и распознавание речи (Web Speech), перевод, эмоции-спрайты, генерация изображений (Pollinations), галерея.

## Локальные модели и CORS

Браузер обращается к API напрямую, поэтому локальный сервер должен разрешать CORS:

- **Ollama** — задайте переменную окружения `OLLAMA_ORIGINS=*`
- **ooba** — запускайте с флагом `--api`
- **KoboldCpp, llama.cpp** — обычно работают сразу

Если подключение падает с `Failed to fetch`, почти всегда дело в CORS или неверном адресе.

## Структура

```
src/
  lib/        логика: api, prompt, worldinfo, macros, cards, generate, slash, i18n…
  store/      состояние (Zustand + IndexedDB)
  components/ общие компоненты и модальные окна
  pages/      вкладки: Chat, Api, Generation, Format, Lorebook, Persona, Interface, Extensions, Characters
public/       орнаменты и демо-персонаж
server.js     сервер без зависимостей для готовой сборки
start.sh      установка, сборка и запуск одной командой
update.sh     обновление из ветки main и запуск
android/      лаунчер для Android (Kotlin, интерфейс — assets/launcher)
```
